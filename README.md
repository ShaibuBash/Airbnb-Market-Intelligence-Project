# Airbnb Market Intelligence Project
## Project Overview
This project analyses Airbnb listings, pricing, host performance and review activity across 10 cities.
The goal was to use data analysis and visualization to identify market patterns and present useful findings through an interactive Power BI dashboard.
## Tools Used
•	Python: Data cleaning and preparation.
•	SQL: Data querying and analysis.
•	Power BI: Data modelling, calculations and dashboard development.
## Datasets
The project uses two datasets:
•	Listings: Contains property details, prices, host information, room types and listing ratings.
•	Reviews: Contains review records, listing IDs and review dates.
## Project Activities
The work covered the following areas:
1.	Data inspection and quality checks.
2.	Data cleaning and preparation.
3.	SQL-based analysis.
4.	Currency conversion of local listing prices to USD for easier comparison across cities.
5.	Power BI data modelling and DAX calculations.
6.	Development of a four-page interactive dashboard.
## Dashboard Pages
•	Airbnb Market Overview
•	Pricing and Property Analysis
•	Host Performance Analysis
•	Review Activity and Listing Scores


## Important Limitations
The datasets do not contain booking, occupancy or actual revenue information. Review text was also unavailable, so sentiment analysis was not included.
The 2021 review data covers only the period up to 1 March 2021.
7. Project Deliverables
The final submission includes the Power BI dashboard, SQL and Python scripts, data quality assessment, KPI definitions, executive summary and dashboard screenshots.
